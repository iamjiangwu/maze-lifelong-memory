# Figure 4 reproduction code

`derived_panels.py` provides `statistics(output_dir)` and `render(output_dir)`.
`inference.py` recalculates animal-clustered decoder contrasts, the behavior
regression, its bootstrap band and exact mouse sign-flip route tests with BH2.
`drawing.py` draws the included values using the publication layout.
The shared `release_rendering` runtime supplies statistical and export helpers.
