# Extended Data Figure 10. Neural preservation and later behavior

Panel a relates six neural readouts to three later behaviors, showing absolute Pearson correlations and BH-corrected stars within each neural-measure row. Panel b partitions behavioral variance associated with reward decoding and level map correlation. Panel c relates level map correlation to four junction turning biases measured during the first 30 min on return.

## Reproduce

Run from the repository root:

```powershell
python figures/extended_data_10/build.py --output-dir outputs/ed10
```
