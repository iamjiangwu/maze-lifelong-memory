# Source Data for Extended Data Figure 10

`panel_a_values.csv` contains the paired neural/behavior observations used by both a and b. Commonality components and profile tests are calculated from these same observations. `panel_c_values.csv` contains paired policies and saved bootstrap display bands.

Matrix cells show Pearson r; significance uses animal-clustered CR1 slopes and BH3 across three outcomes within each neural row. Current values yield 12 significant cells. Commonality partitions pooled two-predictor OLS R². Three profile claims use exact animal-score sign flips with BH3. Policies use animal-clustered CR1 slopes and BH4; saved bootstrap bands are descriptive.

`record_type` (or `row_type`) identifies observations, display summaries and inference rows. IDs identify animals, sessions, pairs, neurons or chains. Correlations and policy probabilities are dimensionless; decoder error is in maze tiles. Undefined values are empty cells. Descriptive coordinates are supplied directly; statistical tests are recalculated from observations.
