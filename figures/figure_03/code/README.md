# Figure 3 reproduction code

`derived_panels.py` provides `statistics(output_dir)` and `render(output_dir)`.
`inference.py` recomputes animal-clustered CR1 tests and Benjamini-Hochberg
correction from the included cycle and pair observations. `drawing.py` draws
saved curves and coordinates and the descriptive regression bands.
The shared `release_rendering` runtime supplies statistical and export helpers.
