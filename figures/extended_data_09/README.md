# Extended Data Figure 9. Additional analyses of the persistent level code

The fifteen panels show population-vector and mean-correlation nulls, decoding, preferred-level changes, alternative partitions, place/level associations, spatial nulls, gap curves, recurrence and experience effects.

Pair-level tests use animal-clustered CR1 uncertainty. Preferred-level and partition comparisons each use BH2. Recurrence and both experience analyses retain full four-metric observation families in companion tables and recompute BH4. Null distributions are saved derived draws.

Run from the repository root:

```powershell
python figures/extended_data_09/build.py --output-dir outputs/ed9
```

The release starts at approved saved derived observations and display arrays. Neural values use the accepted S/HWHM 1 configuration and 0.066 eligibility gate where applicable. Metric-specific eligibility exceptions remain in the input tables. Missing values and support masks are preserved.
