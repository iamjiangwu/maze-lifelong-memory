# Source Data for Extended Data Figure 7

a–c: 59 within-cycle observations per metric; d–f: 36 long-gap observations per metric; level_age_family_points.csv: the fourth long-gap correction-family member.

In d/e, `n_matched_neurons` is the number passing the activity gate;
`n_cimap_matches` is the number registered before that gate.

OLS uses age per 30 days, categorical adjustments, animal-clustered CR1 uncertainty and t(G−1) inference. The within-cycle family contains three metrics; long-gap BH4 also includes level maps, whose observations are retained in level_age_family_points.csv.

`record_type` (or `row_type`) identifies observations, display summaries and inference rows. IDs identify animals, sessions, pairs, neurons or chains. Correlations and policy probabilities are dimensionless; decoder error is in maze tiles. Undefined values are empty cells. Descriptive coordinates are supplied directly; statistical tests are recalculated from observations.
