# Supplementary Table 3. Glossary of behavioral and neural measures

This two page table defines the 23 measures used in the paper. The first page
covers behavior and the second covers neural representations and decoding.
Definitions and units are editable in [data/glossary.json](data/glossary.json).

From the repository root:

```powershell
python reproduce.py --figure table3 --output-dir outputs/table3
```

The builder typesets the definitions; it does not run a scientific analysis.
